## 简短描述（建议 ≤ 132 字）

```text
用你自己的 OpenAI 兼容 API 或本地 Dual Read 代理，翻译网页与 YouTube 双语字幕，网页还支持替换模式。
```

## 详细描述

```text
Dual Read 帮助你用「自己的 API」双语阅读网页和 YouTube 字幕，网页还支持直接替换为译文。

功能
• 按需翻译当前页（工具栏、Alt+T；选词可走右键菜单）
• 双语对照 / 替换模式（Alt+M 切换）
• 视口优先翻译，节省 token；动态页面增量补译
• 可选按站点自动翻译规则
• YouTube 双语字幕复用现有 API，支持单独目标语言和简单字号/位置预设
• 打开桌面 YouTube 视频观看页即显示双语按钮，点击后才开始翻译；安装时声明仅限 YouTube 的站点访问，字幕自动翻译默认关闭
• 使用已有人工或自动字幕，不进行音频转录；暂不支持直播、Shorts、移动站、嵌入播放器及画中画字幕
• 兼容任意 OpenAI 协议端点，或本地 dual-read-server 缓存代理

明确不做
• 不是 VPN、广告拦截、购物助手或通用 AI 侧栏
• 不会把页面默认发到 Dual Read 云——只发到你配置的地址
• 安装时不索要「所有网站」权限

隐私
• 默认零产品遥测
• 远程接口必须 HTTPS（仅 localhost 允许 HTTP）
• API 密钥和自定义 HTTP 请求头仅保存在当前设备；除非明确勾选，否则不会出现在导出文件中
• 启用翻译后的字幕文字与相邻上下文发往你配置的 API；YouTube Cookie 和签名字幕 URL 不会发送给它
• 完整政策：https://github.com/skys-mission/dual-read/blob/main/PRIVACY.md

三步开始
1. 安装后打开 Options
2. 填写 API 地址与 Key（或指向 http://127.0.0.1:8080/v1）
3. 打开网页 → 点击翻译

使用 YouTube 时，打开带字幕的视频，点击原生 CC 旁的双语按钮，或使用插件弹窗的「字幕」页签。升级后如浏览器提示，请接受 YouTube 站点访问，并刷新已打开的视频页。

开源（Apache-2.0）：https://github.com/skys-mission/dual-read
```
